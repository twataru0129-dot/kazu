## 自動更新（v1.3）

準備：iPhone で公開ページを開き「ホーム画面に追加」する。プロフィールと記録が少しある状態にする。「おとなのメニュー → 保存について → アプリの版」を控える。

- [ ] PR をマージして公開（Actions の Deploy to GitHub Pages が成功）したあと、ホーム画面アプリを**一度とじて**（アプリ切り替え画面で上にスワイプ）開き直すと、少しして一度だけ画面が読み込み直され、アプリの版が新しくなる
- [ ] アプリを開いたまま（ホーム画面を表示）別のアプリに切り替え、公開後に戻ると、一度だけ読み込み直されて新しい版になる
- [ ] ゲーム（例：ミニ数独）の途中で別のアプリに切り替え、公開後に戻っても、**画面が勝手に読み込み直されない**。数字を入れた盤面がそのまま
- [ ] そのゲームを「もどる」で一覧へ戻ると、一度だけ読み込み直されて新しい版になる。数独を開くと「つづきから」がある
- [ ] 機内モードで起動しても遊べる。機内モードを解除すると、ホームにいれば新しい版に切り替わる
- [ ] 更新の前後で、プロフィール・記録（おとなのメニュー → きろく）・テストの履歴・設定がそのまま
- [ ] 何度も読み込み直しが続かない（1回で止まる）
- [ ] Safari のタブで開いた場合も同じように更新される
