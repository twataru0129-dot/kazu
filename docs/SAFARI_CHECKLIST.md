# iPhone Safari 実機確認チェックリスト（v1.1）

自動テストは Chromium の画面サイズのエミュレーションで行っています。WebKit（Safari）の自動テストは実行環境に無いため、以下を実機で確認してください。

## 準備
- [ ] 公開ページ（例 `https://<ユーザー名>.github.io/kazu/`）を iPhone の Safari で開く
- [ ] 既存の記録がある場合は、先に「おとなのメニュー」→「バックアップ」で JSON を保存

## アイコン
- [ ] Safari のタブ（ブックマーク／お気に入り）に新しいアイコンが出る
- [ ] 「共有」→「ホーム画面に追加」の画面で新しいアイコンが出る
- [ ] ホーム画面に追加したアイコンが新しい絵柄（ブロックと 5・+・2）

## 操作ドック（下のアドレスバーが出ている状態と、スクロールして縮んだ状態の両方で）
- [ ] あそぶ →「すうじの法則」：数字を入れて「こたえる」がアドレスバーに重ならず、スクロールせずに押せる
- [ ] 「ふしぎな数字マシン」「フラッシュ計算」「こぜに数え」「おかいもの」「計算のくふう」でも同じ
- [ ] 正解後の「つぎへ」がスクロールせずに押せる。押し間違えてアドレスバーに触れにくい
- [ ] 間違えたときの「おしい！」がドックに隠れずに見える
- [ ] 「ミニ数独」「かずの迷路」「かたちパズル」：盤面とドック（数字／ピース／こたえあわせ）が同時に見える
- [ ] けいさん・テスト・まなび（れんしゅう）でも同じ
- [ ] 画面を下までスクロールしても、本文の最後（説明やヒント）がドックに隠れない
- [ ] ホーム画面に追加したアプリ（PWA）でも上の項目を確認（ホームバーにボタンが重ならない）

## まなぶ
- [ ] かけざん・わりざんのタブ（5つ／4つ）が全部見えて、横にスクロールしない
- [ ] かけざん「みる」の場面5：2・3・6 の説明（1さらに ある りんごの かず／おさらの かず／ぜんぶの りんごの かず）が読める大きさ
- [ ] わりざん「みる」の場面5：10・2・5 の説明が読める大きさ
